# SoundBoost

แอป Android ปรับเสียงลำโพงบลูทูธ: อีควอไลเซอร์ เพิ่มเบส เพิ่มความดัง โหมดเสียงสำเร็จรูป
และโหมด MAX ที่ดันลำโพงให้ดังและแน่นขึ้นโดยไม่แตก
ใช้ได้กับ Android 8.0 ขึ้นไป (โหมด MAX ต้องใช้ Android 9 ขึ้นไป)

## วิธีสร้างไฟล์ APK ฟรีด้วย GitHub (ใช้คอมอัปโหลดครั้งเดียว)

1. สมัครหรือล็อกอิน https://github.com
2. กด **+** มุมขวาบน > **New repository** ตั้งชื่อ `SoundBoost` แล้วกด **Create repository**
3. แตกไฟล์ zip บนคอม ในหน้า repo กด **uploading an existing file**
   แล้วลาก**ทุกอย่างในโฟลเดอร์ SoundBoost** ไปวาง (ต้องมีโฟลเดอร์ `.github`, `app`, `gradle`
   และไฟล์ `gradlew` ถ้าไม่เห็น `.github` ให้เปิดการแสดงไฟล์ซ่อนก่อน) แล้วกด **Commit changes**
4. ไปที่แท็บ **Actions** รอประมาณ 3–5 นาทีจนขึ้นเครื่องหมายถูกสีเขียว
   (ถ้ายังไม่เริ่ม ให้กด **Build APK** > **Run workflow**)
5. กดเข้าไปที่งานที่เสร็จแล้ว เลื่อนลงไปที่ **Artifacts** กด **SoundBoost-apk** เพื่อดาวน์โหลด
6. แตกไฟล์ zip ที่ได้ จะเจอ `app-debug.apk` กดติดตั้ง
   (มือถือจะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้กดอนุญาต)

หรือเปิดโฟลเดอร์นี้ใน Android Studio แล้วกด Run ก็ได้

## วิธีใช้

1. เชื่อมลำโพงบลูทูธกับมือถือ
2. เปิด SoundBoost กดสวิตช์ **เปิดปรับเสียง** และอนุญาตการแจ้งเตือน
3. เลือกโหมดเสียง หรือปรับเองที่อีควอไลเซอร์
4. เปิดเพลงในแอปที่ใช้ประจำ ถ้าเพลงเล่นอยู่ก่อนแล้วเสียงไม่เปลี่ยน ให้หยุดแล้วเล่นใหม่

## โหมด MAX

1. กด **วัดลำโพง** แล้วกด **▶ เล่น** จะได้ยินเสียงหึ่งทดสอบ
2. เลื่อนแถบไปทางซ้ายช้าๆ จนเสียงหึ่งเบาลงมาก หรือได้ยินลำโพงสั่นแปลกๆ แล้วกด **ใช้ค่านี้**
   แอปจะตัดเบสที่ต่ำกว่าจุดนั้นทิ้ง ลำโพงจะไม่เสียแรงไปกับเสียงที่เล่นไม่ได้ จึงดังขึ้นและเสียงสะอาดขึ้น
3. ปรับ **แรงขับ** (ดันความดัง) และ **ความแน่น** (ให้เสียงหนาและดังสม่ำเสมอ) ตามชอบ
   ลิมิตเตอร์จะคุมไม่ให้สัญญาณเกินจนแตก แต่ถ้าดันมากเกินไป เสียงจะเริ่มบี้ ให้ลดแรงขับลง

## ทำงานอย่างไร

- ใส่เอฟเฟกต์เสียงของ Android (Equalizer, BassBoost, LoudnessEnhancer) กับเสียงทั้งเครื่อง
- โหมด MAX ใช้ DynamicsProcessing: ตัดเบสต่ำ > คอมเพรสเซอร์ 3 ย่าน > แรงขับ > ลิมิตเตอร์ -1 dB
- รับสัญญาณจากแอปเพลงที่แจ้งว่ากำลังเล่น แล้วใส่เอฟเฟกต์กับแอปนั้นโดยตรง
- ทำงานเบื้องหลังผ่านการแจ้งเตือนถาวร กด **ปิด** ในแจ้งเตือนเพื่อหยุด

ข้อจำกัด: มือถือบางรุ่นปิดการปรับเสียงทั้งเครื่องไว้ ในกรณีนั้นจะได้ผลเฉพาะแอปเพลงที่ส่งสัญญาณ
และแอปปรับเสียงตัวอื่นที่เปิดอยู่พร้อมกัน (เช่น Dolby, Wavelet) อาจชนกัน ให้ปิดตัวอื่นก่อน
